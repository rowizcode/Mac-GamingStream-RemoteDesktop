Optional virtual gamepad setup

Security warning: This weakens macOS code-integrity protection. Do not do it on a work, banking, or security-sensitive Mac. Sunshine streaming still works without it; only the virtual controller is unavailable.

Before you start

  • This guide is for Apple Silicon Macs.
  • Back up important files.
  • Do not disable SIP. This project does not require it.
  • Take a photo of the restore commands near the bottom.

One-time steps

  1. Shut down the Mac completely.
  2. Press and hold the power button until Loading startup options appears.
  3. Choose Options → Continue. Sign in when Recovery asks.
  4. From the menu bar, choose Utilities → Terminal.
  5. Run this command and follow its account/password prompt:
bputil --disable-boot-args-restriction

This selects Permissive Security for the chosen macOS volume. Apple warns that this makes the system easier to compromise.

  1. Then run:
nvram boot-args="amfi_get_out_of_my_way=1"
  1. Restart normally.
  2. Run Install Sunshine.command again so the app is signed with the required HID entitlement.
  3. Connect Moonlight before opening Steam or the game.

Test

Disconnect Moonlight, fully quit the game, reconnect Moonlight with the controller enabled, then launch Steam and the game. The Sunshine log should contain:

IOHIDUserDevice virtual gamepad support is available
Gamepad 0 allocated (IOHIDUserDevice mode)

Restore the normal security policy

Return to Recovery using the same power-button steps and run:

nvram -d boot-args
bputil --full-security

Restart normally. The virtual controller will stop working, while video, audio, keyboard, mouse, and touch remain available.
