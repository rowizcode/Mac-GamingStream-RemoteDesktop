Start here

This package turns an Apple Silicon Mac running macOS 26 or later into a Moonlight streaming host.

Install in three steps

  1. Double-click Install Sunshine.command.
  2. If macOS blocks it, Control-click it, choose Open, then choose Open again.
  3. Follow the installer. Turn Sunshine on under both Accessibility and Screen & System Audio Recording.

Pair the iPhone or iPad

  1. Install Moonlight Game Streaming from the App Store.
  2. Keep the iPhone/iPad and Mac on the same home network for the first pairing.
  3. Open Moonlight. Tap the Mac. A PIN appears on the phone.
  4. On the Mac, open https://localhost:47990, sign in, choose PIN, and enter that PIN.
  5. In Moonlight, open Desktop to control the Mac's current physical desktop.

Recommended Moonlight settings

  • Begin with 1920 × 1080, 60 FPS, H.264, 30–50 Mbps.
  • After it is stable, try HEVC and 60–70 Mbps for better image quality.
  • Use 90/120 FPS only when the Mac display, the game, and the iPhone all support it.
  • For touch control: one-finger tap = left click; two-finger drag = scroll; long press then drag = click and drag.

Controller support

Video, audio, keyboard, mouse, and touch work without changing startup security. The virtual Xbox controller needs one optional Recovery-mode change. Read GAMEPAD-SETUP.html before deciding.

Good to know

  • The installer keeps existing Sunshine credentials, pairing data, and configuration.
  • It backs up the previous app and enables Sunshine after user login.
  • FileVault's pre-login screen cannot be remotely controlled. Log in to the Mac once after a restart.
  • The Web UI certificate is local/self-signed, so a browser warning at localhost is expected.

Experimental: This is an ad-hoc signed, non-notarized community build. It is not an official Sunshine or Lumen release.
